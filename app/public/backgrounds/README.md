# Render backgrounds

360° panoramas from [Poly Haven](https://polyhaven.com/hdris), released under
[CC0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain; no attribution
required). Each has a 3072 × 1536 JPEG, downscaled from Poly Haven's tonemapped JPEG, shown
behind the model, and the 1k HDR used to light the scene as a dome light (ADR-028).

| File          | Poly Haven asset                                                                 |
| ------------- | -------------------------------------------------------------------------------- |
| `sky.*`       | Kloofendal 48d Partly Cloudy (Pure Sky) — `kloofendal_48d_partly_cloudy_puresky` |
| `mountains.*` | Alps Field — `alps_field`                                                        |
| `grass.*`     | JE Gray Park — `je_gray_park`                                                    |
| `city.*`      | Canary Wharf — `canary_wharf`                                                    |
